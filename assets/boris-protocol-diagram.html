The Boris Protocol
Exhaustive analysis > incremental guessing — Boris Cherny
1
STOP
Do not hypothesize. The urge to guess is the signal.
2
Define the Question
Write it down explicitly. Vague question → vague evidence → vague conclusion.
3
Collect ALL Evidence
Before ANY opinion. Every number needs a source — no source → write (?)
4
Trace to Root
Start from observation. Trace backwards to where actual ≠ expected.
5
Multi-Pass Verification
Pass 1: evidence only. Pass 2: patterns. Pass 3: conclusions.
6
Act and Verify
Fix root cause, not symptom. Verify in real environment.

incremental guesses

vs
1
Boris pass
5 min, exact root cause
